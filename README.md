# MyMusic

Лёгкий музыкальный плеер для Windows: поиск в открытом каталоге Audius, воспроизведение
полных треков, фоновая работа в трее и компактный виджет переключения.

Приложение написано на Python + PySide6 (Qt 6), собирается в переносимую папку
PyInstaller и проверено на Windows 11 x64. Полный отчёт приёмки с методикой и сырыми
замерами — [docs/acceptance-report.md](docs/acceptance-report.md).

## Возможности

- Поиск по названию и исполнителю: задержка 350 мс, отмена устаревших запросов,
  по 30 результатов на страницу, без подмены старых ответов новыми.
- Реальное воспроизведение полных треков Audius без ключа, аккаунта и подписки.
- Очередь: запуск результата заменяет очередь, отдельная команда добавляет в конец;
  удаление текущего выбирает следующий трек на паузе; перестановка не прерывает звук;
  «Предыдущий» после 3 секунд перематывает в начало; конец очереди останавливает плеер.
- Избранное и настройки хранятся локально в SQLite/JSON; при запуске очередь и позиция
  восстанавливаются на паузе.
- Основное окно можно закрыть в трей, управление остаётся в виджете 360×112 логических
  пикселей; меню трея: открыть, виджет, пауза/продолжить, настройки, выход.
- Светлая и тёмная темы, системный шрифт Segoe UI, клавиатурная навигация, видимый фокус.
- Один экземпляр приложения: повторный запуск активирует уже открытое окно.

## Стек

- Python 3.14, PySide6 6.12 (Qt 6.12), QtMultimedia (FFmpeg/Windows Media Foundation).
- SQLite (WAL) для библиотеки, JSON для настроек, QtNetwork для HTTP, PyInstaller 6.22.
- Источник: официальный API Audius (`https://api.audius.co/v1`) с резервным
  `https://discoveryprovider.audius.co/v1`; только HTTPS и доверенные редиректы.

## Запуск из исходников

```powershell
python -m venv .venv
.venv\Scripts\pip install -e .
.venv\Scripts\python -m mymusic
```

Данные по умолчанию: `%LOCALAPPDATA%\MyMusic` (`settings.json`, `library.db`,
`logs\mymusic.log`, кэш обложек). Каталог можно переопределить: `--data-dir <путь>`.

## Сборка переносимой версии

```powershell
.venv\Scripts\python -m PyInstaller --noconfirm --clean --onedir --windowed `
    --name MyMusic --paths src packaging/entry.py
```

Результат — `dist\MyMusic\MyMusic.exe` (около 145 МиБ, установщик не требуется).
Сборка не подписана, поэтому SmartScreen может показать предупреждение.

## Проверки

```powershell
.venv\Scripts\python -m unittest discover -s tests -t . -v
.venv\Scripts\python -m mymusic --self-test --play-seconds 8 --report docs/selftest-report.json
dist\MyMusic\MyMusic.exe --self-test --play-seconds 8 --report docs\packaged-selftest-report.json
```

Self-test выполняет реальный поиск, воспроизведение потока, проверки хранилища, очереди,
восстановления настроек, офлайн-ошибки и отсутствия секретов в журнале. Звук в self-test
отключён (громкость 0 и mute), поток при этом реально скачивается и декодируется.

Замеры производительности (упакованная сборка, 3 повтора, звук отключён):

```powershell
powershell -File scripts/run_perf_matrix.ps1
powershell -File scripts/measure_startup.ps1 -Runs 5
powershell -File scripts/measure_impact.ps1
powershell -File scripts/check_single_instance.ps1
```

Фактические результаты: пауза 0,078% CPU и 47 МиБ, звук + виджет 0,598% CPU и 65,6 МиБ,
поиск 0,108% CPU, рост памяти за час +7,44 МиБ, старт до окна 1,20 с, влияние на другой
процесс 0,55%. Подробности и ограничения — в отчёте приёмки.

## Ограничения

- Один источник — Audius. Каталог состоит из независимых и загруженных артистов,
  а не из топ-чартов мейджоров; отсутствующий трек честно показывается как «нет результатов».
- YouTube и Spotify не используются: скрытое извлечение аудио и обход DRM недопустимы,
  Spotify требует подписку и решение пользователя.
- Офлайн-режим не обещан: буфер может доиграть, затем показывается явная ошибка.
- Замеры относятся к одной машине (Windows 11 26200, 12 логических ядер, 15,9 ГиБ ОЗУ)
  и зафиксированным версиям; на другом оборудовании цифры будут иными.
- Сон/пробуждение, отключение монитора, масштабирование 100–200% и задержка отрисовки
  кнопок проверены кодом и тестами частично; ручные проверки отмечены в отчёте приёмки.
