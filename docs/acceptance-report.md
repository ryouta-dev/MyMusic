# Отчёт приёмки MyMusic 0.1.0

Дата: 2026-11-17. Платформа: Windows 11 26200, x64, 12 логических ядер, 15,9 ГиБ ОЗУ.
Источник: открытый каталог Audius через официальный API без ключа и аккаунта
(см. [provider-validation.md](provider-validation.md)).

## 1. Сборка и состав

- Исполняемая сборка: `dist\MyMusic\MyMusic.exe` (onedir, windowed, без установщика и подписи).
- Команда сборки:
  ```powershell
  .venv\Scripts\python -m PyInstaller --noconfirm --clean --onedir --windowed `
      --name MyMusic --paths src packaging/entry.py
  ```
- Версии: Python 3.14.8, PySide6 6.12.0 (Qt 6.12.0), PyInstaller 6.22.3,
  pyinstaller-hooks-contrib 2026.10, Windows Multimedia/FFmpeg-плагины Qt.
- Размер дистрибутива: около 145 МиБ (`dist\MyMusic`), из них Qt/PySide6 — около 116 МиБ.
  Включены плагины `platforms\qwindows.dll`, `multimedia\ffmpegmediaplugin.dll`,
  `multimedia\windowsmediaplugin.dll`, OpenSSL/TLS-плагины Qt.
- Сторонние компоненты и лицензии: [THIRD_PARTY_NOTICES.txt](../THIRD_PARTY_NOTICES.txt),
  текст LGPL-3.0 — `packaging/licenses/LGPL-3.0.txt`. Qt/PySide6 используются по LGPL-3.0
  с динамической компоновкой; PyInstaller — GPL с исключением для загрузчика.
  Сборка не подписана, поэтому SmartScreen может показать предупреждение.
- Проверки выполнялись на этой же машине; отдельная «чистая» Windows без Python недоступна,
  поэтому отсутствие среды разработки эмулировалось запуском только из `dist\MyMusic`.

пересечений; реальный поток Audius играл 8,0 с (позиция 8016 мс, MP3 320 кбит/с,
хост `validator.eeba4a6ca56a0d87af802270217c2a51.r2.cloudflarestorage.com`); офлайн-адрес
дал ошибку `offline`; завершение освободило ресурсы; журнал не содержит URL, токенов
и параметров запросов. Звук в self-test отключён (громкость 0 и `setMuted(true)`).

## 3. Измерения упакованной сборки

Методика: `scripts\run_perf_matrix.ps1` запускает упакованный `MyMusic.exe --perf idle|playing|search`
по 3 повтора на сценарий, прогрев 60 с, выборка каждые 2 с; CPU — прирост процессорного
времени процесса / прошедшее время / 12 логических ядер × 100; память — private bytes процесса;
GPU — счётчики Windows «GPU Engine» (лучшее усилие). Замеры выполнены без отладчика.
По просьбе пользователя (во время замеров он играет) звук на время прогонов отключён:
громкость 0 и `setMuted(true)`, при этом поток Audius скачивается и декодируется, то есть
аудиоконвейер работает; слышимого вывода нет. Это зафиксировано в поле `volume` отчётов.

| Сценарий | Длительность | Средний CPU | CPU p95 (худший повтор) | Private avg | Private max | GPU avg/max |
|---|---|---|---|---|---|---|
| Пауза, все окна скрыты | 300 с × 3 | 0,078% | 0,195% | 47,0 МиБ | 47,3 МиБ | нет данных (счётчик недоступен) |
| Звук + виджет | 600 с × 3 | 0,598% | 1,040% | 65,6 МиБ | 69,5 МиБ | нет данных (счётчик недоступен) |
| Звук, оба окна скрыты | 600 с × 3 | 0,321% | 0,583% | 63,9 МиБ | 65,6 МиБ | нет данных (счётчик недоступен) |
| Поиск с открытым окном | 120 с × 3 | 0,108% | 0,519% | 55,4 МиБ | 56,7 МиБ | нет данных (счётчик недоступен) |

Сырые данные: [perf-summary.json](perf-summary.json) и отчёты `perf-<сценарий>-r1..r3.json`.
CPU — среднее по трём повторам, p95 — худший повтор; разброс среднего CPU:
пауза 0,072–0,081%, звук+виджет 0,364–0,736%, звук скрыто 0,314–0,327%,
поиск 0,102–0,117%. Цели docs/01: ≤0,2% CPU на паузе, ≤1% CPU при звуке с виджетом,
≤150 МиБ private на паузе, ≤200 МиБ при звуке — все выполнены с запасом.

Простой: в каждом повторе 150 выборок за 300 с, один процесс (`process_count: 1`,
дочерних процессов нет), private bytes стабильны 46,7–47,3 МиБ, изменение за прогон
≤0,03 МиБ, средний CPU 0,078% — цель ≤0,2% выполнена. Счётчики GPU при скрытом
интерфейсе не дали значений, то есть постоянного GPU-рендеринга не наблюдалось.

Звук + виджет: все три повтора закончились в состоянии `playing` (3–4 трека за 10 минут;
в одном повторе был один автопереход после ошибки провайдера, лимит 30 не достигнут),
private 65,3–66,0 МиБ, изменение 4,3–7,0 МиБ, CPU каждого повтора ≤0,736% — цель ≤1%
выполнена, память ниже 200 МиБ. Звук, оба окна скрыты: все повторы `playing` (по 3 трека),
изменение 2,8–3,2 МиБ, CPU ≤0,327%, private ≤65,6 МиБ. Поиск: все повторы закончились
в `ready` с 30 результатами, private 55,2–55,5 МиБ, изменение 2,5–3,3 МиБ, CPU ≤0,117%.

Влияние на другой процесс: [impact-report.json](impact-report.json), один и тот же
однопоточный локальный тест (sha256 + целочисленный цикл, 20 с) по 3 запуска без плеера
и с играющим плеером при скрытых окнах. Медианы 400,0 и 397,8 итерации/с, ухудшение
0,55% при предварительной цели ≤2%; это одна машина и один тест, шум измерения учтён
тремя повторами.

Час непрерывного воспроизведения: [perf-hour.json](perf-hour.json), 60 минут в режиме
`--perf playing` на упакованной сборке, звук отключён (громкость 0 и mute), окна скрыты.
Проиграно 10 треков, один автопереход после ошибки провайдера, финальной ошибки нет.
Private bytes 62,15 → 69,59 МиБ, рост 7,44 МиБ при цели ≤20 МиБ. Рост не монотонный:
к 30-й минуте 72,6 МиБ, затем значения вернулись к 69,5–69,7 МиБ и держались до конца
(подъёмов 103, спусков 111 по выборкам каждые 2 с). Средний CPU 0,346%, p95 0,907%.

Старт: `scripts\measure_startup.ps1 -Runs 5` запускает `MyMusic.exe` с временным каталогом
данных и измеряет время до появления главного окна. Результаты: 1588, 1197, 897, 1859
и 956 мс, медиана 1197 мс — в цели ≤2 с для тёплого запуска. Разброс объясняется кэшем
файловой системы и проверкой новых DLL антивирусом. Полный холодный старт после очистки
кэша ОС не измерялся (требует административных действий).

Один экземпляр: `scripts\check_single_instance.ps1` запускает два упакованных процесса
с одним каталогом данных; второй завершился за ≤10 с с кодом 0, окно первого осталось
открытым ([single-instance-report.json](single-instance-report.json)). В ходе этой проверки
обнаружено, что Qt 6.12 допускает два `QLocalServer` с одним именем; защёлка переведена
на `QSharedMemory`, сокет оставлен только для команды активации.

## 5. Известные ограничения

- Один источник — Audius; каталог не равен «всем популярным песням». YouTube и Spotify
  не используются: скрытое извлечение аудио и обход DRM недопустимы, Spotify требует
  подписку и решение пользователя. Jamendo требует регистрацию (D06) и не подключён.
- Учётная запись не используется: Audius доступен без ключа и входа, поэтому отдельного
  «выхода из аккаунта» в приложении нет; настройки показывают состояние источника.
- Сборка не подписана; установщик, автообновление и публикация не выполнялись.
- Замеры относятся к указанной машине и версиям; на другом оборудовании цифры будут иными.
- Сетевые перебои во время воспроизведения могут дать ошибку после буфера; офлайн-режим
  не обещан.
- Длительные сценарии (сон/монитор/DPI) не подтверждены вручную и не выдаются за проверенные.
- 20 циклов открытия/скрытия проверены тестом по состоянию окон и очереди; отдельные счётчики
  CPU/памяти для этого сценария не снимались — ресурсы в это время покрыты замерами простоя.

## 7. Запуск, выход и очистка данных

- Запуск: `dist\MyMusic\MyMusic.exe`; данные — `%LOCALAPPDATA%\MyMusic`
  (`settings.json`, `library.db`, `logs\mymusic.log`, кэш обложек).
- Выход: меню трея → «Выйти»; звук останавливается, БД и аудиоустройство освобождаются.
- Очистка: «Настройки» → «Очистить локальные данные» (очередь, избранное, настройки,
  кэш обложек); вручную можно удалить каталог `%LOCALAPPDATA%\MyMusic` при закрытом приложении.
- Перенос: каталог `dist\MyMusic` целиком; отдельный установщик не требуется.

## 8. Открытые вопросы docs/04

| Вопрос | Решение / граница |
|---|---|
| Первый источник и полнота каталога | Audius: открытый API без ключа и аккаунта, полные треки. Каталог — независимые и загруженные артисты, а не топ-чарты мейджоров; это ограничение источника, а не сбой. |
| Допустимость Premium | Не требуется: Audius не просит подписку для поиска и стриминга; Spotify не используется. |
| Реальные API-доступ и регион | Проверено с этой машины; в другом регионе доступность не гарантируется. Клиент пробует основной gateway и резервный `discoveryprovider.audius.co`, затем показывает понятную ошибку. |
| Окончательная трактовка виджета | Отдельное перемещаемое окно 360×112 логических пикселей, поверх окон — выключено по умолчанию (рабочее допущение docs/01). |
| Фактическая Windows | Windows 11 26200, x64; сборка и замеры выполнены здесь. Другие версии не обещаются. |
| Выбор основы и пригодность по измерениям | Собственная реализация Python 3.14 + PySide6 6.12; один процесс, фактические CPU/память — в разделе 3. Electron-варианты отклонены из-за лишних процессов и неподтверждённого фона. |
