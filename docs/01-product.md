# 01. Продукт и требования

## 1. Подтверждено пользователем
- Платформа — персональный компьютер Windows.
- Самостоятельное приложение с поиском музыки в интернете, не пульт для открытого Spotify/браузера.
- Воспроизведение в фоне и лёгкое переключение треков через виджет.
- Очень малое потребление ресурсов и минимальное влияние на другие процессы.
- Сейчас нужны документы и архитектура; другой агент должен автономно выбрать лучший путь и реализовать приложение до проверяемой конечной цели.
- Источник гибкий: упомянуты YouTube, Spotify и другие варианты.

## 2. Рабочие допущения, не отдельное согласие пользователя
- Виджет — небольшое перемещаемое окно на рабочем столе, не панель Widgets Windows и не внедрение под значки рабочего стола.
- Поверх других окон — выключаемая настройка, по умолчанию выключена.
- Русский интерфейс; рабочее имя MyMusic, не утверждённый бренд.
- Первая целевая система — Windows 11 x64; фактическую версию ОС проверить перед сборкой. Другие версии не обещать без теста.
- Один источник в первой версии. Источник и допустимость подписки остаются открытыми.
- Локальные файлы допустимы только как технические тестовые материалы, не замена интернет-каталогу.

## 3. Минимальная полноценная версия
### Основной сценарий
Запуск → настройка доступного источника → поиск исполнителя/песни → выбор результата → реальное воспроизведение → очередь → закрытие основного окна в трей → управление через виджет → полное завершение из трея.

### Поиск
- Ввод запроса, задержка 350 мс, отмена предыдущего запроса, постраничная выдача по 30 результатов.
- Название, исполнитель, источник, длительность при наличии; честная отметка фрагмента, если доступно только превью.
- Только реальные результаты API. Старый ответ не заменяет результаты нового запроса.
- Состояния: до ввода, загрузка, нет результатов, нет интернета, ограничение API, нужна авторизация, ошибка с повтором.

### Воспроизведение и очередь
- Играть/пауза, предыдущий/следующий, громкость, позиция и перемотка только при поддержке источником.
- Нажатие результата запускает его и задаёт текущую очередь из загруженных результатов; дальнейшие страницы сами очередь не меняют.
- Отдельно добавить в конец очереди, удалить и переставить; сохранить порядок. Удаление текущей записи останавливает её и выбирает следующую на паузе; если следующей нет — idle. Перестановка не прерывает текущий трек. Повторное нажатие результата заменяет очередь, команда добавления — нет.
- «Предыдущий»: после 3 секунд — начало трека при доступной перемотке, иначе предыдущая запись.
- Конец очереди останавливает воспроизведение; повтора и случайного порядка в первой версии нет.
- Повреждённый или недоступный трек: сообщение, возможность повтора/следующего; никакого бесконечного автопропуска.
- Избранное с локальным сохранением; без синхронизации с аккаунтом сервиса в первой версии.
- Сеть потеряна: буфер может доиграть, затем явная ошибка. Не обещать автономную работу.

### Виджет и фон
- Примерный размер 360 × 112 логических пикселей, масштабирование Windows 100–200%.
- Название/исполнитель, предыдущий, пауза, следующий, открыть основное окно; обложка необязательна.
- Неактивные возможности заблокированы с понятной подсказкой. Все команды управляют тем же воспроизведением, что основное окно.
- Перетаскивание за свободную область, сохранение положения; после отключения монитора вернуть в видимую область.
- Закрытие виджета скрывает только виджет; закрытие основного окна скрывает окно в трей с уведомлением при первом использовании.
- Меню трея: открыть, показать/скрыть виджет, пауза/продолжить, настройки, выйти.
- «Выйти» останавливает звук, освобождает ресурсы и завершает процесс. Трей — не системная служба.
- Сон ПК не равен фону: звук во сне не обещать. После пробуждения обновить источник; не начинать звук неожиданно.
- Автозапуск выключен, включается только пользователем.

### Настройки и сохранение
Источник/статус подключения, громкость, видимость и положение виджета, поверх окон, тема системы/светлая/тёмная, очистка локальных данных, выход из аккаунта. При запуске восстановить очередь и положение, но оставаться на паузе; поддержку точного продолжения определяет источник.

## 4. Интерфейс
Основное окно: поиск, результаты, очередь/избранное, нижняя панель воспроизведения; настройки отдельной страницей или диалогом. Не делать стартовую рекламную страницу.
Системный шрифт Segoe UI, нейтральная светлая/тёмная палитра и один акцент, без визуализатора и постоянной анимации. Клавиатура, видимый фокус, названия элементов для средств доступности, крупные кнопки управления, обрезка длинного названия с подсказкой.

## 5. Не входит в первую версию
Скачивание музыки, извлечение аудио YouTube, обход DRM/рекламы/доступа, рекомендации, тексты песен, эквалайзер, облачный сервер, собственные аккаунты, синхронизация устройств, несколько одновременно играющих источников, мобильная версия. Не вводить регистрацию в MyMusic: авторизация нужна только если её требует источник.

## 6. Цели нагрузки — не измеренные обещания
Для упакованной версии, после прогрева 60 секунд, на одном зафиксированном ПК:
- Пауза, окна скрыты: средний CPU ≤ 0,2% всей машины за 5 минут.
- Музыка играет, основное окно скрыто, виджет показан: средний CPU ≤ 1% за 10 минут.
- Суммарная private bytes всех процессов приложения: ≤ 150 МиБ на паузе, ≤ 200 МиБ при воспроизведении.
- Нет постоянно активного GPU-рендеринга скрытого интерфейса; отдельно записать фактический GPU.
- Цель реакции кнопки: 95-й процентиль ≤ 150 мс до подтверждения команды интерфейсом; задержку начала сетевого звука измерять отдельно.
- Старт до интерактивного окна ≤ 2 с при тёплом запуске; холодный запуск записывать отдельно.
- За час устойчивого воспроизведения прирост private bytes после прогрева ≤ 20 МиБ, без монотонного роста.
- Дисковый кэш обложек ≤ 50 МиБ, без дискового кэша аудио по умолчанию.
Если цель не достигнута: измерить причину, оптимизировать и явно согласовать компромисс, а не менять цифры молча. Размер дистрибутива измеряется отдельно от оперативной памяти.
